# Simple Hi Program

This is a simple Python program that outputs "Hi" as requested in the requirements.

## Files

- `main.py`: The main program that outputs "Hi"
- `test_main.py`: Test file to verify the functionality
- `run_tests.sh`: Shell script to run both the program and tests
- `verify.py`: Verification script that demonstrates everything works
- `README.md`: This documentation file

## Usage

### Run the main program
```bash
python3 main.py
```

### Run the tests
```bash
python3 test_main.py
```

### Run both program and tests
```bash
bash run_tests.sh
```

### Verify everything works
```bash
python3 verify.py
```

## Requirements Fulfilled

The program fulfills the request "test Hi" by:
1. **Main functionality**: Providing a `say_hi()` function that returns "Hi"
2. **Program execution**: A main program that prints "Hi" when run
3. **Testing**: Comprehensive tests to verify the functionality works correctly
4. **Documentation**: Clear documentation and usage instructions

- **Language**: Python 3
- **Testing Framework**: unittest (built-in Python testing framework)
- **Code Structure**: Clean, documented functions with proper separation of concerns
- **Verification**: Multiple ways to verify the implementation works correctly
